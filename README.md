# MyDB

My custom database implementation

## Resriction

This database implementation is for unix based systems only.
It is written using the following specs:
- OS: Debian GNU/Linux 12 (bookworm)
- gcc: Debian 12.2.0
- make: GNU Make 4.3

## Inspiration

Inspiration is taken from a [Blog Post by James Smith](https://build-your-own.org/database/)
